# F1 Immobiliare — Territory Acquisition System

Repository operativo separato dedicato al lavoro del **F1 Territory Scout**.

## Responsabilità di questo repository

- Today's Mission / Next Best Action
- Giro territoriale per Comune → Microzona → Via → Civico → Palazzo
- Citofono guidato
- Porta a porta guidato
- Registrazione Segnale / Notizia / Prospect con livelli N0–N6 e attendibilità F1–F4
- Telefonate di oggi collegate alle vie lavorate
- Contatti professionali pubblici provenienti da Radar Edilizio
- Import locale di numeri autorizzati/legittimamente acquisiti, senza pubblicarli su GitHub

## Repository separati collegati

- HUB: `josephsocialmedia2-spec/launcher-dashboard`
- Seller Radar / Market Intelligence / Brief: `josephsocialmedia2-spec/immobili-in-zona`
- Social / pubblicazione: `josephsocialmedia2-spec/open-social-scheduler`

## Regola F1

TERRITORIO → SEGNALE → NOTIZIA → PROSPECT → QUALIFICAZIONE → FOLLOW-UP → APPUNTAMENTO → VALUTAZIONE → INCARICO → RELAZIONE.

Nessuna informazione viene trasformata automaticamente in fatto. Ogni elemento conserva fonte, livello e attendibilità.
